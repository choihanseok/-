## Flow
VERIFIED LOGIN Challenge → Account lookup by phone → Session create → opaque access/refresh tokens → token hashes persisted.

## Security
- raw access/refresh tokens are not persisted
- HMAC-SHA256 token digests are stored
- refresh rotates both access and refresh tokens
- old refresh token becomes unusable after rotation
- session revoke is idempotent
- revoked sessions cannot authenticate
- access and refresh expiration are checked separately
- expired refresh marks session EXPIRED
- login session rejects a verified challenge with a non-login purpose
