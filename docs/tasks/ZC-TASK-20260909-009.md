## 목적
공통 Order와 서비스 제공자를 연결하는 Matching 공통모듈의 최소 기반을 추가한다. 특정 서비스명에 종속되지 않고 향후 DRIVING/QUICK/FLOWER/ERRAND 및 추가 Service Module이 재사용할 수 있도록 구성했다.

- MSR_MTC_006 / ZR-MTC-006 서비스 제공 연결 기반

## 구현
- `MatchingMode`: AUTO / MERCHANT / MANUAL_ADMIN / EXTERNAL
- `MatchingStatus`: REQUESTED / OFFERED / ACCEPTED / REJECTED / REASSIGNED / CANCELLED / FAILED
  - 상세 MatchingStatus는 원본에 확정 코드가 없어 PROJECT_DEFINED 보조 상태로 관리
  - 공통 OrderStatus를 대체하지 않음
- Matching Entity / Repository 계약
- InMemoryMatchingRepository
- SqliteMatchingRepository
- `008_create_matchings.sql` additive migration
- MatchingService
  - Matching 시작: Order → SEARCHING
  - Provider 제안/배정: Order → ASSIGNED
  - Provider 승인: Order → ACCEPTED
  - Provider 거절: provider assignment 제거 + Order → SEARCHING
  - 재배정 시 이전 Matching attempt 보존 + 새 attempt 생성
- Role + Permission + Scope + Ownership 연동
  - `MATCHING.VIEW`
  - `MATCHING.ASSIGN`
  - `MATCHING.RESPOND`
  - SERVICE_ADMIN SERVICE scope
  - PROVIDER ASSIGNED scope
  - deny by default
- OrderStatusHistory 연동
